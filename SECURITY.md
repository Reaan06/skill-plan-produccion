# Security Policy

## Supported versions

The latest version on the default branch is supported. Older versions are supported only when the repository owner confirms it in a release or security notice.

## Report a vulnerability privately

Do **not** open a public issue or pull request for a security vulnerability. Use the repository's private GitHub Security Advisory form:

<https://github.com/Reaan06/skill-plan-produccion/security/advisories/new>

If GitHub Security Advisories is unavailable, contact the owner through the public GitHub profile:

<https://github.com/Reaan06>

Ask for a private security-reporting channel and do not include sensitive details in a public message.

## Include

- A concise description and affected version or commit.
- Reproduction steps or a minimal safe proof of concept.
- Impact, affected files or behavior, and any known prerequisites.
- Suggested mitigation, if available.
- A safe contact method for follow-up.

## Exclude

Do not include real credentials, access tokens, private keys, personal data, customer data, private project details, or weaponized exploit code. Redact logs and use synthetic examples.

## Response and disclosure

We aim to acknowledge reports within 7 calendar days and provide an initial triage update within 14 calendar days, but these are targets rather than guarantees. We will coordinate severity assessment, remediation, and disclosure timing with the reporter when practical. Please allow a reasonable remediation window before public disclosure.
